## Shape of the part

Electron main/renderer split, but with an unusual twist: **the desktop app has almost no renderer
code of its own.** The orb window loads the *web* client with `?desktop=orb` query parameters, so
`web/src/App.jsx` is the orb UI. Desktop's own 5,400 LOC are nearly all **main-process** concerns:
window management, settings, backend installation, wake-word, updates, and remote access.

Only three HTML surfaces are truly desktop-local: `settings.html`, `unavailable.html`, and
`orb-unavailable.html`.

## Renderer security posture

Every `BrowserWindow` in the app is created with the same hardened recipe
(`main.mjs:650`, `main.mjs:715`, `orb-window.mjs:68`):

```js
webPreferences: {
  contextIsolation: true,
  nodeIntegration: false,
  sandbox: true,
  backgroundThrottling: false,   // orb windows only
  preload: preloadPath,
}
```

Plus, on the settings window: `setMenuBarVisibility(false)`,
`setWindowOpenHandler(() => ({ action: 'deny' }))`, and `will-navigate` → `preventDefault()`.

### `backgroundThrottling: false` is load-bearing

Both orb windows disable background throttling with the same comment: the floating window is
normally **unfocused**, and Chromium would throttle its timers. That would delay Web Audio playback
receipts, which the Gateway interprets as failed playback and retries. **Do not remove this flag** —
it is a protocol correctness requirement, not a performance tweak.

### URL validation (`security.mjs`)

| Function | Rule |
| --- | --- |
| `validateAppUrl(value)` | Throws unless `https:`, **or** `http:` on a loopback host (`127.0.0.1`, `localhost`, `[::1]`). Returns the origin only |
| `isSameOrigin(value, expected)` | Origin equality, exception-safe |
| `isLoopbackUrl(value)` | Loopback-host test |
| `isSafeExternalUrl(value)` | `http:`/`https:` only — gates `shell.openExternal` so a malicious URL cannot reach `file:` or a custom scheme |

`desktopOrbUrl(value, opts)` is the single place the orb URL is composed. It appends
`desktop=orb` plus `orbSkin`, `autoHideSeconds`, `wakeWordEnabled`, `lang`, `surface`, and
`session`. Skin ids pass through `normalizeOrbSkinId` from `shared/orb-skin-catalog.mjs`, and
built-in ids additionally get a legacy `orbStyle` parameter written for compatibility with an older
`web/dist`.

## IPC bridge — the real desktop API

`preload.cjs` (144 LOC) exposes exactly one global, `window.qwenAudioAgentDesktop`, over
`contextBridge`. **This object is the complete, and only, main↔renderer contract.** 33 members:

### `send` — fire-and-forget (renderer → main)

| Method | Channel |
| --- | --- |
| `dragStart(x,y)` / `dragMove(x,y)` | `drag-start` / `drag-move` — both guarded by `Number.isFinite` in `sendPoint()`; a non-finite coordinate is silently dropped rather than sent |
| `dragEnd()` | `drag-end` |
| `setTaskCardCount(count)` | `task-card-count` |
| `openSettings()` | `open-settings` |
| `wake()` | `wake` |
| `acceptWakeWordAudio(audio, sampleRate)` | `wake-word-audio` |
| `lifecycleReady()` | `lifecycle-ready` |
| `openExternal(url)` | `open-external` — rejects non-strings before sending |
| `quit()` | `quit` |

### `invoke` — request/response (renderer → main → renderer)

Surface / session: `loadSurface`, `setSurface`, `setConversationSession`, `enterHide`,
`loadLifecycle`, `pauseWakeShortcut`, `resumeWakeShortcut`.
Settings: `loadSettings`, `saveSettings`, `loadRuntimeStatus`, `setNodePath`, `openLogs`.
Backends: `detectBackends({force})`, `installBackend`, `configureBackend`.
Updates: `loadUpdaterStatus`, `checkUpdates`, `installUpdate`.
Remote access: `remoteAccessStatus`, `enableRemoteAccess`, `disableRemoteAccess`,
`createRemoteInvitation`.
Skins: `importSkin`, `removeSkin`.

### `on` — subscriptions (main → renderer)

`onTaskCardPlacement`, `onLifecycle`, `onClientSettings`, `onBackendInstallProgress`,
`onUpdaterStatus`.

**Every subscriber follows the same three-part safety pattern**, and new ones must too:
1. non-function callback → return a no-op disposer rather than throwing;
2. wrap the raw IPC listener so the renderer never sees the Electron `event` object;
3. return a disposer that calls `removeListener`.

`onTaskCardPlacement` additionally **sanitizes the payload in the preload** — coercing `placement`
to `'above' | 'below'` and defaulting a non-finite `orbOffsetX` to `0` — so malformed main-process
data cannot reach renderer layout code.

## State management

State is split across four owners, none of them a state library.

### 1. Persisted settings — `settings-store.mjs`

Two files under an explicitly-supplied config directory:

| File | Contents |
| --- | --- |
| `config.env` | User settings **including credentials** |
| `ui-state.json` | Window geometry, orb placement, and similar conveniences |

Rules encoded here that are easy to violate:

- **`configDir` is mandatory.** Omitting it throws `QWAUDIO_GATEWAY_CONFIG_DIR_REQUIRED`. An
  embedding host must isolate its data directory from the standalone app; there is deliberately no
  default.
- **Files are `0o600`, directories `0o700`** — the settings file holds credentials.
- **Reading never creates anything.** `load()` does not `mkdir`; the startup gate runs before the
  host has decided to start, and "not configured yet" must not materialize a directory.
- **Config resolution order** is stored file first, then live `process.env` for unset slots —
  mirroring how the Gateway itself loads `config.env`.
- **A corrupt `ui-state.json` is treated as absent**, never as a startup failure, and is overwritten
  on the next save.

`settings-config.mjs` (529 LOC) supplies the pure half: `parseSettings`, `normalizeSettings`,
`realtimeSettingsConfigured`, `applySettingsEnvironment`, `updateSettingsContent`.

### 2. Presence / lifecycle — `DesktopPresence` class

The one classical stateful object (`desktop-presence.mjs`). Holds `state`
(`active` | `hidden` | `waking`), `shortcut`, `shortcutRegistered`, `shortcutPaused`, and pushes
transitions to the renderer over the `lifecycle` channel. `wake()` restores, shows, and focuses the
window, emitting `waking` from `hidden` and an `activity` refresh otherwise. Every access is guarded
by `window.isDestroyed()`.

The shortcut pause/resume pair exists so the global wake shortcut does not fire while the settings
window is open — `main.mjs:729` resumes it on settings-window close.

### 3. Layout — `desktop-surface-layout.mjs`, pure functions over frozen constants

| Constant | Value |
| --- | --- |
| `DESKTOP_ORB_WIDTH` × `HEIGHT` | 172 × 204 |
| `DESKTOP_PANEL_WIDTH` × `HEIGHT` | 440 × 680 |
| `DESKTOP_TASK_SURFACE_WIDTH` | 360 |
| `DESKTOP_TASK_CARD_HEIGHT` / `_GAP` | 54 / 8 |
| `DESKTOP_TASK_STACK_PADDING` / `_LIFT` | 8 / 14 |
| `ORB_PLACEMENT_MARGIN` (`orb-placement.mjs`) | 24 |

Six pure functions (`desktopConversationPanelBounds`, `desktopOrbAnchorFromPanel`,
`desktopSurfaceSize`, `desktopOrbBounds`, `desktopTaskPlacement`, `desktopSurfaceLayout`) compute
geometry from `(bounds, workArea, taskCount)`. **All window geometry decisions live here**, not in
`main.mjs` — which is what makes them testable without Electron.

### 4. Renderer state

Delegated wholesale to the web client — see
[`frontend-architecture-web.md`](./frontend-architecture-web.md). Desktop injects into it only via
URL parameters (`desktopOrbUrl`) and the `client-settings` IPC channel.

### Skin store

`skin-store.mjs` (347 LOC) imports user skin packages from ZIP archives:
`extractZipArchive` → `validateSkinPackage` → `importSkin`, with `webpDimensions()` parsing WebP
headers directly to validate sprite sheets. `effectiveOrbSkin` falls back when a referenced skin is
missing, and `listSkins`/`removeSkin` manage the store. Because this ingests untrusted archives,
`validateSkinPackage` is the security boundary for the skin feature.

### Wake word

`sherpa-onnx` 1.13.4 runs detection **in a worker** (`wake-word/worker.mjs`), with
`model-manager.mjs` fetching and unpacking models at runtime — which is why `tar-stream` and
`unbzip2-stream` are dependencies. Detected audio reaches the renderer's Gateway socket via
`acceptWakeWordAudio`.

## UI components

There is no component framework in the desktop part. Surfaces are hand-written HTML + vanilla JS:

| Surface | Files | Purpose |
| --- | --- | --- |
| Settings window | `settings.html`, `settings.js`, `settings.css` | Backends, voice, updates, remote access, skins |
| Orb unavailable | `orb-unavailable.html`, `orb-unavailable.js` | Shown when the Gateway is unreachable |
| Unavailable | `unavailable.html` | Generic failure surface |
| Orb | *(none — loads `web/dist` via `desktopOrbUrl`)* | The web client in orb mode |
