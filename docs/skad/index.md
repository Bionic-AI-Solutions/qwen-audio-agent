## Project overview

| | |
| --- | --- |
| **Type** | Monorepo (npm workspaces) with **8 documented parts** |
| **Primary language** | JavaScript ESM — sources are `.mjs`, no TypeScript, no build step for server code |
| **Architecture** | Domain-partitioned service + event-driven WebSocket protocol; local-first |
| **Runtime** | Node `^22.22.2 \|\| ^24.15.0 \|\| >=26.0.0`, npm `>=10` |
| **Tracked files** | 985 |
| **License** | Apache-2.0 |

**What it is:** a realtime voice runtime that keeps an agent in the conversation while longer work
continues in the background. It does not replace the user's agent — it connects to existing ACP
agents (Qwen Code, OpenCode, OpenClaw), remote A2A agents, or a custom adapter, and layers a voice
conversation plus a presence UI over a documented Gateway protocol.

### The five facts that explain most of the codebase

1. **The Gateway protocol is the product boundary.** Version 5.7.0, client protocol GCP6 6.0.0,
   **29 frozen capabilities**. Clients branch on a capability string, never a version.
2. **`package.json#exports` publishes 42 entry points reaching into every workspace.** A file under
   `server/src/` or `desktop/src/` can still be public API.
3. **`web/` is not a leaf.** Desktop loads `web/dist` in an orb window; mobile `import()`s
   `web/src/App.jsx` at runtime. One change ships to three clients.
4. **There is no database and no container deployment.** Persistence is versioned JSON snapshots on
   local disk; the Gateway is a process on the user's machine, reached remotely over Tailscale HTTPS.
5. **The Realtime frontend / background Agent boundary is the core invariant.** Voice must never
   block on delegated work — see `docs/architecture/deep-dive.md`.

## Getting started

### Set up

```bash
nvm install && nvm use          # honors .nvmrc (22.22.2)
npm ci                          # not npm install
cp .env.example .env            # set DASHSCOPE_API_KEY at minimum
```

### Run

```bash
npm run dev        # server + web concurrently
npm run gateway    # builds web, then starts the Gateway
npm run desktop    # Electron app
npm run tui        # terminal client
```

### Verify before any PR

```bash
npm run lint && npm test && npm run build && npm run release:check
```

### Per-part quick start

| Part | Command | Notes |
| --- | --- | --- |
| server | `npm run gateway` | `pregateway` builds `web/` first — the Gateway serves `web/dist` |
| web | `npm run dev --workspace web` | Vite on `0.0.0.0` |
| desktop | `npm run desktop` | `npm run desktop:build:local` for an unsigned local DMG |
| mobile | `npm run mobile:sync` then `mobile:ios` / `mobile:android` | Needs Xcode / Android Studio |
| tui | `npm run tui` | Half-duplex audio by default; AEC binary needed for full duplex |
| cli | `npm run cli -- --help` | |
| examples | `npm run example:smart-cockpit` | Runs `:install` first |
