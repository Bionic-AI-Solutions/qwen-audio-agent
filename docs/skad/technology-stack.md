## Per-part stacks

### server (`@qwen-audio-agent/server`) — backend

| Category | Technology | Version |
| --- | --- | --- |
| HTTP | Express | ^4.22.2 |
| WebSocket | `ws` | ^8.21.1 |
| Agent protocol | `@agentclientprotocol/sdk` (ACP) | 1.3.0 |
| Tool protocol | `@modelcontextprotocol/sdk` (MCP) | 1.30.0 |
| Computer use | `@qwen-code/open-computer-use` | ^0.2.3 |
| Config | `yaml` | 2.9.0 |
| Schema | `zod` | ^4.4.3 |

**Architecture pattern:** domain-partitioned service. `server/src/` splits into 16 domain modules
(`access`, `agent`, `app`, `backend`, `client`, `conversation`, `core`, `delivery`, `domain`,
`frontend`, `process`, `providers`, `session`, `task`, `transport`, `voice`) composed by
`app/gateway-application.mjs` and booted by `app/bootstrap.mjs`. Communication with clients is
event-driven over a WebSocket Gateway protocol rather than a REST-first design.

### web (`@qwen-audio-agent/web`) — web

| Category | Technology | Version |
| --- | --- | --- |
| UI | React | ^19.1.0 |
| DOM | react-dom | ^19.1.0 |
| Build | Vite | ^7.0.0 |
| React plugin | `@vitejs/plugin-react` | ^4.7.0 |
| Markdown | react-markdown ^10.1.0 + remark-gfm ^4.0.1 |

**Architecture pattern:** component-based SPA. Builds to `web/dist/`, which the server serves and
the root package exposes as `./web-dist/*`. No Redux/MobX — state is React hooks plus a shared
gateway client from `shared/`.

### desktop (`@qwen-audio-agent/desktop`) — desktop

| Category | Technology | Version |
| --- | --- | --- |
| Shell | Electron | ^43.2.0 (dev) |
| On-device speech | `sherpa-onnx` | 1.13.4 |
| Archive handling | `tar-stream` 3.1.7, `unbzip2-stream` 1.4.3 |
| Transport | `ws` | 8.21.1 |
| Packaging | electron-builder | 26.15.7 |

**Architecture pattern:** Electron main/renderer split with a hardened preload bridge
(`desktop/src/preload.cjs`, `security.mjs`). Entry `desktop/src/main.mjs`. `sherpa-onnx` provides
local wake-word / speech processing, with archives fetched and unpacked at runtime — hence the
tar/bzip2 dependencies.

| Category | Technology | Version |
| --- | --- | --- |
| Native bridge | Capacitor core | 8.5.1 |
| Platforms | `@capacitor/android`, `@capacitor/ios` | 8.5.1 |

### tui (`@qwen-audio-agent/tui`) — cli

| Category | Technology | Version |
| --- | --- | --- |
| Transport | `ws` | ^8.18.3 |
| Audio I/O | native bindings in `tui/native/` (PortAudio) + `macos-voice-io.mjs` |

**Architecture pattern:** terminal client speaking the Gateway protocol directly, with
platform-specific voice I/O (`portaudio-voice-io.mjs`, `macos-voice-io.mjs`, `pcm-audio.mjs`) and a
command surface in `terminal-commands.mjs`.

### cli (`@qwen-audio-agent/cli`) — cli

Zero runtime dependencies. Ships the `qwenaudio` binary (`cli/bin/qwenaudio.mjs`) and delegates to
`shared/` and `scripts/` for gateway lifecycle. Deliberately dependency-free so the published npm
package stays installable anywhere.

### shared (`shared/`) — library

No manifest of its own; consumed via the root package `exports` map, which publishes 25+ named
entry points (`./gateway-protocol`, `./gateway-client-sdk`, `./backend-adapter-sdk`,
`./realtime-provider`, `./memory-provider`, `./knowledge-provider`, …).

**Architecture pattern:** published extension surface. `shared/` is the contract layer every client
and third-party extension compiles against; changes here are public API changes.

### examples (`examples/`) — library

Reference implementations, each independently installable (`smart-cockpit/` has its own
`service/`, `agent/`, `gateway/`, `client/`, `bench/`, `bootstrap/`, `test/`; plus `voicemem/`,
`backend-adapter/`, `custom-conversation-client/`). Excluded from root ESLint.
