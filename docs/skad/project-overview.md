## What this project is

**qwen-audio-agent** v1.11.0 — "A realtime voice runtime that keeps AI agents talking, working, and present."

A realtime voice runtime that keeps an agent in the conversation while longer work continues in
the background. It does not replace the user's agent: it connects to existing ACP agents (Qwen
Code, OpenCode, OpenClaw), remote A2A agents, or a custom adapter, and layers a voice conversation
plus a presence UI on top, over a documented Gateway protocol.
