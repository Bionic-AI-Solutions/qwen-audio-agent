## i18n discipline

`docs/i18n-parity.md` documents an enforced parity rule between `*.md` and `*.zh.md`, and
`scripts/sync-docs-site.mjs` runs as a `pre` hook for every `docs:*` npm script. **Any new page
added under `docs/` participates in this site.** SKAD output lives in `docs/skad/` and should be
excluded from the VitePress build (see the Deployment Guide) so it does not create parity failures
or publish internal scan artifacts.
